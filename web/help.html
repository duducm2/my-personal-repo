Openings CRUD

Job openings board only.

ATS means Applicant Tracking System — the software employers use to collect and screen applications (e.g. Workday, Greenhouse, Gupy, LinkedIn Easy Apply). An ATS application is the online form on that system (name, email, phone, education, résumé upload, hiring message, and similar fields). Use Shift+F / Shift+A to generate answers from that form’s page text and import them into the opening’s copy panel for pasting back into the ATS.

Shortcut Action Notes

Shift+R Generate openings prompt Job openings board
Shift+I Import openings Job openings board
Shift+F Generate form-fill prompt (ATS application) Paste ATS page text; see glossary above
Shift+A Import form result into opening copy panel After AIB returns ATS field JSON
