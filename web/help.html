Openings CRUD

Job openings board only.

ATS means Applicant Tracking System — the software employers use to collect and screen applications (e.g. Workday, Greenhouse, Gupy, LinkedIn Easy Apply). An ATS application is the online form on that system (name, email, phone, education, résumé upload, hiring message, and similar fields). With a job opening open, use Alt+F / Alt+A to generate answers from that form’s page text and import them into the opening’s copy panel for pasting back into the ATS. Use Alt+C / Alt+L to generate a cover letter prompt from the job / project description and import the AI JSON into a one-page PDF.

Pages

  • Job openings — home · pipeline bento board
  • Job portals — market boards only (LinkedIn, Gupy, Greenhouse…)
  • Target companies — employer dossiers + careers / ATS links. Default order is AI recommendation rank within International (I-n) then Regional (L-n) tracks (pinned still float to the top). International means any country outside Brazil (US, EU, Asia, etc.), not US-only; Regional is Brazil / local. Career path filters include Data Analyst, Product Owner, Digital Solution Architect, and Data Scientist. Use the Rec track filter to focus one group; reorder with ↑↓ on the card or Alt+↑ / Alt+↓ on a focused / open company.
  • Career profile — fields & resumes

Country flags are inferred from region / scope / location text. Foreign HQ with local footprint shows a second BR flag plus a BR industry cue.
