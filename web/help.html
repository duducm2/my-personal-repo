Keyboard shortcuts

Navigation

Everywhere (when not typing in a field).

Shortcut Action Where
Shift+O Job openings (home) All pages · also / on refresh
Shift+J Job portals All pages
Shift+C Target companies All pages
Shift+P Career profile All pages
Shift+H This help page All pages
Esc Close search / modal / resume viewer; otherwise openings home All pages

Search

Shortcut Action Where
Alt+S Show / hide search bar and focus it; when search closes, focus the first card Openings · Portals · Companies
← → ↑ ↓ Move focus between result cards Openings · Portals · Companies
A–Z · 0–9 Jump to the first card whose title starts with that character (press again to cycle matches) Openings · Portals · Companies
Ctrl+Enter Open the focused portal URL in a new tab Portals (card focused)
Esc Close modal if open; else clear search text; else clear all filters Openings
Esc Dismiss search (when open) Portals · Companies

Language & display

Shortcut Action Where
Shift+1 Portuguese field values (and resumes on Profile) Profile · Companies · Openings
Shift+2 English field values Profile · Companies · Openings
Shift+0 Show both languages Profile · Companies · Openings
Shift+D Toggle summary / detail Profile
Shift+E Collapse / expand panels Profile

Openings CRUD

Job openings board only.

Shortcut Action Notes
Shift+N Add new opening and open dossier Not while typing
Ctrl+S · Ctrl+Enter Save (update) all openings Works while typing
Shift+Delete Delete the open dossier Confirms first; modal must be open

Save

Shortcut Action Where
Ctrl+Enter Save changes to canonical CSVs Profile · Companies · Openings
Ctrl+Enter Open focused portal; otherwise save (same as Ctrl+S) Portals
Ctrl+S Save changes Openings · Portals · Companies · Profile

Pages

  • Job portals — market boards only (LinkedIn, Gupy, Greenhouse…)
  • Target companies — employer dossiers + careers / ATS links
  • Career profile — fields & resumes
