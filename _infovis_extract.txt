Mapeamento Visual
● Foram estudadas:
– Como tabelas de dados podem organizar dados brutos a 
serem representados visualmente.
– Como estruturas visuais podem representar dados
● A interligação entre tabelas de dados e estruturas visuais é 
feita por meio de um processo chamado mapeamento 
visual.
– Objetivo: associar cada variável da tabela de dados a uma 
propriedade gráfica ou espacial.
● A quantidade de estruturas visuais que se pode elaborar 
para uma mesma tabela de dados pode ser elevada.
– Como escolher? Que diretrizes utilizar para orientar essa 
escolha?

● Propósito de Visualização de Informação é propor 
representações visuais e interativas que procurem otimizar 
os recursos da percepção visual humana no sentido de 
facilitar o entendimento de informação disponível nos 
dados.
● É interessante, portanto, analisar algumas características 
do sistema visual humano

Dados multivariados
● Já vimos técnicas para aumentar quantidade de dados 
codificada no espaço (Card et al., 1999):
– Composição
– Alinhamento
– Quebra (folding)
– Recursão (baseada em zoom)
– Sobrecarga (overloading)
– Small Multiples
● Elas são técnicas para lidar com dados com várias 
variáveis, até certo ponto.
– Sobrecarga e Small Multiples
● Que outras técnicas temos disponíveis para isso?
3
 Visualização de Informação
Técnicas de visualização de 
dados multivariados
● Técnicas (classificadas quanto à primitiva gráfica usada na 
renderização) (Ward et al., 2010) 
– Técnicas baseadas em ponto
– Técnicas baseadas em linha
– Técnicas baseadas em região
– Combinações de técnicas

4
 Visualização de Informação
Representado mais dimensões: 
considerações gerais
● Se necessárias mais dimensões, alternativas são:
– Incorporar dimensões
● Outras dimensões podem usar outros atributos que não o espaço (há 
restrições de quantas dimensões incluir assim)
● Muitas técnicas fazem isso...
– Displays múltiplos
● Sobrepor ou justapor vários gráficos, cada um contendo algumas das 
dimensões
– Small Multiples faz isso.
– Reduzir o conjunto de dimensões
● Usuário escolhe; ou
● Algoritmo determina as dimensões com informação mais útil.
– Redução da quantidade de dimensões
● Transformar as N dimensões em K dimensões (não necessariamente as 
mesmas), tentando preservar relacionamentos pré-existentes entre 
dados

Visões e transformações de 
visão
● Uma vez que os dados da tabela de dados estão 
representados em uma estrutura visual, é possível ao 
usuário interagir com essa estrutura, alterando seu formato 
ou seu conteúdo de modo a extrair dela mais informação do 
que ela apresenta estaticamente.
– Transformação de visão: cria novas visões da estrutura visual 
de acordo com a necessidade do usuário.
● Card et al. (1999) apontam três tipos de transformações de 
visão:
– Investigações de local
– Distorções
– Controles de ponto de vista
4
Visualização de Informação
Investigações de local
● Usam o local em que um dado está em uma estrutura visual 
para revelar informações adicionais da tabela de dados.
● Exemplos:
– 1) técnica de detalhes-sob-demanda adotada no programa 
Film Finder de Ahlberg e Shneiderman (1994)
– 2) lentes mágicas (magic lenses) de Fishkin e Stone (1995)

3  Visualização de Informação
Textos: tarefas
● Tarefas associadas com análise de textos
– Procurar por palavras, frases, tópicos
– Procurar relacionamentos entre palavras, frases, tópicos ou 
documentos
– Procurar por padrões ou outliers em um texto ou em 
documentos
– Ajudar a compreender, de maneira geral, a que se refere um 
dado documento ou conjunto de documentos.
● As tarefas definirão que estruturas visuais desejamos, e que 
tabelas de dados serão necessárias para isto
4  Visualização de Informação
Dados brutos, tabelas de dados
● Textos podem ser tidos como dados brutos no modelo de 
Card et al. (1999).
● Tabelas de dados devem indicar dados como: 
– Quais os objetos (termos) de análise em nosso(s) texto(s)?
– Qual a importância de cada objeto?
● Frequência? Veremos adiante
– Quais as relações entre esses objetos?
– Quais as relações entre esses objetos e os textos de onde 
foram extraídos?
